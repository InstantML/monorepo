# Onboarding, team, and billing

Hosted onboarding takes a user from sign-in to an organization, plan, storage
choice, and first SDK key.

## Signup and first key

New hosted users choose a plan and enter the dashboard through onboarding. Free
hosted signups can receive a copy-once SDK key immediately. Paid plans may
redirect through hosted checkout before write access is unlocked.

## Plans

The current product tiers are Free, Pro, and Premium:

| Plan | Price | Included storage | API requests / month |
| --- | ---: | ---: | ---: |
| Free | $0 / org / month | 2 GB | 500k |
| Pro | $199 / org / month | 1 TB | 25M |
| Premium | $699 / org / month | 5 TB | 150M |

Premium can include customer-owned self-hosted GCP ClickHouse setup for teams
that need tenant data routed to their own deployment.

For the full limit table, storage overage, request overage, and API rate-limit
policy, see [Pricing, limits, and billing](/guides/pricing-limits-billing).

## Invitations

Admins can invite teammates from Settings. Invite links open the hosted invite
page, preview the organization and role, then require the recipient to sign in
before accepting.

Admins can resend or revoke pending invitations while they are active.

## Billing states

When an organization is pending payment or payment-failed, write routes can
return a payment-required error. The dashboard exposes hosted billing actions
for checkout, plan changes, customer portal access, and cancellation where the
organization role allows it. Paid subscriptions include Stripe-metered hosted
storage and API request overage items.
