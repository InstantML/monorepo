# Integrations

The Integrations tab is a status-oriented overview of the product surfaces that
connect training jobs, APIs, and migration data to InstantML.

## Current surfaces

- Python SDK for run creation, metrics, artifacts, buffering, and replay.
- Hosted REST API for SDK, dashboard, import, export, usage, and artifacts.
- W&B, MLflow, and Neptune-shaped JSON import routes.

## Migration paths

Use the import routes when you have transformed source data:

```bash
curl https://api.instantml.ai/api/imports/wandb \
  -H "Authorization: Bearer $INSTANTML_API_KEY" \
  -H "Content-Type: application/json" \
  --data @wandb-transformed.json
```

Use SDK shadow logging when you want new training jobs to log to InstantML and
W&B at the same time during evaluation.
