# Artifacts, files, and media

Artifacts connect metric behavior to the files and evidence produced by a run.

![Run Detail files evidence](/images/product/dashboard-artifacts-evidence.png)

## Artifact browser

The Artifacts tab focuses on the selected run context. Select a run first, then
use the tab to inspect that run's artifact metadata and stored bytes.

![Artifacts browser](/images/product/dashboard-artifacts-browser.png)

Artifacts can represent:

- Uploaded files.
- External file references.
- Checkpoints.
- Rollouts.

The same tab also shows rich logged objects for the selected run, such as
tables, histograms, media previews, and evaluation outputs. Those objects can
link to artifact bytes, but they are not artifact rows themselves.

## Files in Run Detail

Run Detail includes a Files section that previews the selected run's artifacts
and rich objects without introducing a separate storage layer. The left rail
groups checkpoints, media and rich objects, and files. Selecting an item opens a
bounded preview for tables, histograms, media, and artifact metadata.

## Safe previews

Same-origin image, audio, and video artifacts can preview in Run Detail and
Compare when bytes are stored through InstantML. Unsupported or external-only
artifacts fall back to copy/download actions. Stored bytes are served through
`/api/artifacts/{artifact_id}/download`; public artifact rows expose opaque
InstantML URIs rather than raw object-store URLs.

Rich media objects can link to artifact bytes from the same run. Metadata-only
objects and artifacts remain inspectable, but they cannot be downloaded through
the same-origin route until bytes are uploaded to InstantML.

## Checkpoint workflow

Checkpoint artifacts are visible in Run Detail and in the Checkpoints
workspace. They can carry restore metadata such as source run and step. When
checkpoint bytes are stored through the API, downloads go through the
same-origin artifact download route.

## API snippets

Artifact and API tabs expose copyable identifiers and route snippets so a user
can fetch artifacts or inspect API behavior without digging through browser
network panels.
