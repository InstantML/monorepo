# Distributed and Insights

Some training workflows need more than a scalar line chart. InstantML includes
Runs workspace panels for line, bar, value histogram, dot, scatter,
seed/group distribution, and selected-run logged histogram timeline
visualizations, plus research-oriented surfaces for distributed runs and
loaded-summary analysis. These views operate on the selected run, selected
runs, or the currently loaded summary page; they do not pull every run across
every page in a project.

## Distributed

![Distributed dashboard](/images/product/dashboard-distributed.png)

Use Distributed for rank-aware training runs and reducer-style inspection. This
surface is aimed at jobs where individual ranks or workers produce metrics that
need grouped views.

## Insights

![Insights dashboard](/images/product/dashboard-insights.png)

Insights is for exploratory views over the loaded run summaries, such as
grouped reducers, hyperparameter scatter, loaded-summary cluster cards,
parallel-coordinate traces for sweep/HPO tradeoffs, and evaluation metric
summary cards. These traces are exploratory and summary-only; they are not
saved Runs workspace panels.

## When to use each surface

| Surface | Use it when |
| --- | --- |
| Runs | You need a fast broad scan |
| Metrics | You need one metric charted carefully |
| Run Detail | You need to inspect one run |
| Compare | You have a candidate set and need differences |
| Distributed | Rank/worker context matters |
| Insights | You want exploratory summaries over the loaded/selected runs |
