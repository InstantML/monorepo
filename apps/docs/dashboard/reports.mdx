# Reports and saved views

The Reports tab currently surfaces saved dashboard views and a small snapshot of
the current run context. It is not a long-form collaborative report editor.

## What appears

- Saved view names and scopes.
- Current run count and selected-run count.
- The selected metric.
- A compact best-value card for the current overview.

## Save a useful view

1. Open Runs.
2. Choose project, search, status, metric, chart mode, selected runs, and panel
   layout.
3. Save the view from the dashboard controls.
4. Open Reports to see the saved view listed.

Use saved views for repeatable daily comparisons, sweep checkpoints, or a
stable demo setup.
