# Reports

The Reports tab creates persisted report documents for experiment recaps,
ablation notes, and teammate handoffs. Reports can combine prose, markdown,
code snippets, images, callouts, and live PanelGrids that query run data.

## What appears

- A list of reports in the workspace.
- A block editor for each report.
- Live PanelGrid blocks that render charts from runsets.
- Share links for read-only report viewing.
- Markdown export for copying a report outside InstantML.

## Create a useful report

1. Open Reports.
2. Create a report and add prose blocks for the narrative.
3. Add a PanelGrid block for charts that should stay live.
4. Share the report link or export it as Markdown.

Use reports for concise experiment reviews rather than as a replacement for the
main Runs and Compare workspaces.
