# Run Detail

![Run Detail](/images/product/dashboard-run-detail.png)

Run Detail is the place to slow down and inspect one run.

## Summary

The top of the page shows run identity and status:

- Run name.
- Duration and source metadata availability.
- Status.
- Tags and notes.
- Metric key count.
- Artifact count.
- Latest and best metric summaries when available.

## Local run sections

Run Detail has local sections. These are not global dashboard tabs.

| Section | Use |
| --- | --- |
| Summary | Main status, tags, notes, and metric summaries |
| Data | Config and structured run data |
| Logs | Stdout/stderr style logs for the selected run |
| Files | Artifact, checkpoint, media, table, histogram, and evaluation evidence |
| System | Source/system metadata captured by the SDK |
| Graph | Conditional relationship/evidence graph surfaces when graph data exists |

Logs and object manifests load only when the relevant local section is opened.

## Tags and notes

Use the small editor to update tags and notes without leaving the run. These
fields are searchable and appear in Compare.

## Files and artifacts

The Files section previews checkpoints, uploaded files, media objects, tables,
histograms, and binary classification evaluation bundles through existing
artifact and object routes. Classification eval previews render PR/ROC curves,
a confusion matrix, per-class metrics, and optional prediction rows from typed
rich-object data rather than screenshots. Download actions go through the API
rather than exposing raw storage URLs.
