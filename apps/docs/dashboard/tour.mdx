# Dashboard tour

The dashboard is organized around repeated research work: scan many runs,
inspect metric behavior, open one run, then compare candidates.

## Navigation

The left rail groups surfaces into three sections:

| Group | Surfaces |
| --- | --- |
| Operate | Runs, Metrics, Distributed |
| Data | Datasets, Artifacts, Insights |
| System | Run Health, Reports, Settings, API |

Run Detail is not a rail item — you reach it by opening a run. Comparison is not
a rail item either; it lives inside the Runs **Table** view. The top-right
account menu switches workspaces and opens settings or billing.

## Runs workspace

![Runs workspace with selected runs](/images/product/dashboard-runs.png)

Use Runs for the broadest view of a project:

- Filter by project, status, search text, and sort mode.
- Select runs from the rail.
- Toggle between **Panels** (run selector plus chart canvas) and **Table** (a
  flat, sortable run list with an embedded comparison).
- Export selected runs as bounded CSV, or review stop requests, from the **Runs
  actions** menu.
- Review maintained summary values without loading full metric history.
- Build line panels from metric series, summary panels from metric aggregates,
  scatter panels from two loaded numeric run fields, seed/group distribution
  panels, and selected-run logged histogram timeline panels.
- Save named workspace views when the layout should survive a reload.

## Organizations and workspaces

![Organization workspace switcher](/images/product/dashboard-org-workspaces.png)

Use the top-right account menu to see the active workspace, switch
organizations, create a personal or organization workspace, and open settings
or billing for the current workspace.

## Metrics

![Metrics dashboard](/images/product/dashboard-metrics.png)

Metrics is line-chart first. A metric browser on the left groups logged keys by
namespace; the chart supports smoothing, a step/time x-axis, a linear/log
y-axis, grouped averages, and a series table you can show, hide, or pin from.
Chart export downloads the plotted CSV sample or an SVG image of the visible
graph.

## Run Detail

![Run detail page](/images/product/dashboard-run-detail.png)

Run Detail focuses on one run. A KPI cockpit summarizes step progress, the
headline eval metric, loss, throughput, GPU utilization, and ETA, with header
actions to fork a checkpoint, jump to Compare, or request a stop. Its tabs cover
the overview, metrics, artifacts, logs, config and source context, and lineage.

![Run Detail files evidence](/images/product/dashboard-artifacts-evidence.png)

The Artifacts tab shows checkpoints, rich objects, evaluation bundles, media, and
artifact metadata for the selected run without loading those payloads on the
initial summary view.

## Compare

![Compare dashboard](/images/product/dashboard-compare.png)

Comparison lives at the top of the Runs **Table** view. Select two or more runs
in the table and they render side by side with a reference run, goal-aware
deltas, and addable metric columns. Use it after the Runs workspace has narrowed
the candidate set.

## Distributed and Insights

![Distributed dashboard](/images/product/dashboard-distributed.png)

Distributed is a rank-aware view for one selected run: reducer lines, rank
coverage, per-rank snapshots, heatmaps, and outliers from metrics logged with
`run.log_rank_metrics(...)`.

![Insights dashboard](/images/product/dashboard-insights.png)

Insights has two views — **GPU & System** usage and **Run Analysis** (grouped
reducers, hyperparameter scatter, k-means clusters, evaluation summary cards, and
parallel-coordinate sweep traces). Both operate over the loaded or selected run
summaries.

## Checkpoint forks and lineage

![Checkpoint fork modal](/images/product/dashboard-checkpoint-fork.png)

Checkpoint rows expose download, resume-code, and fork actions. Forking creates
a linked child run record only; training starts when a user or script attaches
to that run and logs new data.

![Lineage graph showing a forked child run with no direct children yet](/images/product/dashboard-lineage-graph.png)

The Lineage tab shows the selected run's direct parent, checkpoint, and bounded
child context. The captured state is a forked child run with no direct children
yet.

## Artifacts

![Artifacts workspace](/images/product/dashboard-artifacts-browser.png)

The Artifacts workspace shows versioned collections first: aliases such as
`latest` and `best`, manifest entries, retention/delete controls for owners and
admins, and bounded producer/consumer lineage. Raw run files and media remain
available through the Run Detail Artifacts tab so legacy evidence stays separate
from the version registry.

## Reports

![Reports editor](/images/product/dashboard-reports-editor.png)

Reports are block-based writeups with live panel grids, share links, Markdown
export, and legacy LLM-summary rendering for existing report documents.
