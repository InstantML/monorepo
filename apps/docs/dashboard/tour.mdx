# Dashboard tour

The dashboard is organized around repeated research work: scan many runs,
inspect metric behavior, open one run, then compare candidates.

## Runs workspace

![Runs workspace with a large sweep](/images/product/dashboard-runs.png)

Use Runs for the broadest view of a project:

- Filter by project, status, search text, and sort mode.
- Select runs from the rail.
- Review maintained summary values without loading full metric history.
- Build line, bar, histogram, or dot panels from logged metric keys.
- Save named workspace views when the layout should survive a reload.

## Organizations and workspaces

![Organization workspace switcher](/images/product/dashboard-org-workspaces.png)

Use the top-right account menu to see the active workspace, switch
organizations, create a personal or organization workspace, and open settings
or billing for the current workspace.

## Metrics

![Metrics dashboard](/images/product/dashboard-metrics.png)

Metrics is chart-first. Use it when you know the metric you care about and want
to compare series behavior across selected runs.

## Run Detail

![Run detail page](/images/product/dashboard-run-detail.png)

Run Detail focuses on one run: tags, notes, status, metric summaries, config,
source context, logs, files, system information, and graph-style run evidence.

![Run Detail files evidence](/images/product/dashboard-artifacts-evidence.png)

The Files tab shows checkpoints, rich objects, media, and artifact metadata for
the selected run without loading those payloads on the initial summary view.

## Compare

![Compare dashboard](/images/product/dashboard-compare.png)

Compare lets you inspect selected runs side by side or row by row. Use it after
the Runs workspace has narrowed the candidate set.

## Research dashboards

![Distributed dashboard](/images/product/dashboard-distributed.png)

Distributed and Insights are research-oriented views for rank-aware
metrics, grouped reducers, loaded summaries, and exploratory analysis.

![Insights dashboard](/images/product/dashboard-insights.png)

These views are designed for large sweeps and distributed training runs where a
single scalar chart is not enough context.

## Checkpoint forks and lineage

![Checkpoint fork modal](/images/product/dashboard-checkpoint-fork.png)

Checkpoint rows expose download, resume-code, and fork actions. Forking creates
a linked child run record only; training starts when a user or script attaches
to that run and logs new data.

![Lineage graph](/images/product/dashboard-lineage-graph.png)

The Graph tab shows the selected run's direct parent, checkpoint, and child
context.

## Artifacts

The Artifacts workspace combines selected-run artifact rows, rich-object
previews, download actions, and aggregate counts. Media previews appear when
artifact bytes are stored through InstantML; external references remain
metadata-only.

## Reports

![Reports editor](/images/product/dashboard-reports-editor.png)

Reports are block-based writeups with live panel grids, share links, Markdown
export, and legacy LLM-summary rendering for existing report documents.
