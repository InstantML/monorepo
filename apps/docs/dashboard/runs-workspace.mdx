# Runs workspace

![Runs workspace](/images/product/dashboard-runs.png)

The Runs workspace is the daily command center. It combines a run selector,
summary stats, visualization panels, saved views, and a bounded server-backed
run list.

## Search and sort

Use the search field for names, tags, notes, configs, and indexed run context.
Bare text such as `reward stability` keeps implicit-AND matching. Add precise
filters with `tag:baseline`, `status:finished`, `name:"long context"`,
`-tag:debug`, `(tag:baseline OR tag:candidate) notes:ablated`, or
`re:/seed-(13|14)/`. The help icon beside the dashboard search box mirrors this
syntax and invalid searches keep the last valid results visible.

Sort modes include:

- Newest.
- Selected metric latest value.
- Selected metric best value.
- Name.
- Status.
- Duration.

## Bulk selection

The run rail supports:

- A master checkbox for the visible page.
- Shift-click range selection.
- A banner to select all matching runs when more runs match than fit on the
  current page.

Large selection pages use a lightweight selection projection so the UI does not
fetch full metric aggregates for every selected run.

## Export selected runs

Use **Export CSV** in the Runs command bar to download the selected runs and
their bounded project, metric, attribute, artifact, rich-object row, and import
metadata. The dashboard calls `GET /api/export?format=csv&run_ids=...`, so the
download follows the same org, project, role, and API-key rules as the API.

Synchronous selected-run export is capped at 100 run IDs. If nothing is
selected, or the selection is above the cap, the command bar announces the
reason instead of silently exporting a partial subset.

## Panels

Automatic mode creates a capped high-signal set of line panels from logged
metric keys. Manual mode starts blank so you can add only the charts you need.

Current visualization panel types:

- Line panels for metric series.
- Bar panels for latest values.
- Value histogram panels for latest-value distributions across the current run
  set.
- Dot panels for point-style comparisons.
- Scatter panels for two numeric loaded-run fields, such as a config value
  versus a best metric aggregate.
- Distribution panels for visible-sample seed or ablation stability by a
  categorical config, metadata, status, or first-tag field. Small groups render
  strip points plus a median; larger groups add compact box summaries.
- Logged histogram timeline panels for one primary run and one explicit
  histogram object key. These use `GET /api/runs/:id/objects?kind=histogram`
  with a key filter and render the latest 100 frames as a compatible-bin
  heatmap or a selected-frame fallback when bins changed.
  Add them by typing the histogram object key; metric rows are only suggestions
  when a scalar metric happens to share the same key.

![Logged histogram timeline panel](/images/product/dashboard-logged-histogram.png)

Line panels load selected-run series through bounded chunked requests. Dense
series render paths on canvas while preserving axes, legends, hover readouts,
raw values, and smoothed values when smoothing is active. Large comparisons use
the stable chart palette first, then dashed line styles after the palette wraps
so overlapping runs stay distinguishable.

Scatter, distribution, bar, value histogram, and dot panels use already loaded
run summaries, so they do not fetch full metric histories. Their scope is
selected runs when a selection is active, otherwise the visible loaded run page
capped by the panel limit. Scatter and distribution fields can come from metric
summaries, config values, metadata, duration, status, first tag, or created
time. Scatter and distribution panels are summary-only and do not make metric
series or rich-object reads. These summary panels do not include lasso
selection, density overlays, or project-wide all-matching queries.

Parallel coordinates remain in **Insights** as an exploratory HPO/sweep view
over loaded summaries rather than a saved Runs workspace panel.

Line panels include chart CSV and SVG image export for the visible plotted sample.
Summary panels are designed for fast visual comparison inside the workspace;
use selected-run CSV export when you need raw run rows.

## Layouts and saved views

Panels can be moved, resized, collapsed, edited, and opened fullscreen. Named
layouts are saved through the control-plane workspace-view API.

## Keyboard shortcuts

| Shortcut | Action |
| --- | --- |
| `Cmd/Ctrl+K` | Quick search |
| `?` | Shortcut help |
| `Esc` | Dismiss top overlay |
| `Cmd/Ctrl+Z` | Undo workspace change |
| `Cmd+Shift+Z` / `Ctrl+Y` | Redo workspace change |
| `Cmd/Ctrl+.` | Collapse or restore run selector |
| `Cmd/Ctrl+J` | Move focus between Runs selector and canvas |
| Left/Right Arrow | Traverse fullscreen panels |
