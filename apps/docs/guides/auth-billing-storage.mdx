# Auth, billing, and storage

This page connects the user-facing operational pieces: identity, API keys,
billing state, and storage.

## Browser sessions

Humans use browser sessions for the dashboard through the hosted InstantML
identity flow.

Browser sessions are scoped to an organization and role.

## SDK API keys

SDKs, uploaders, importers, exports, and automation use bearer API keys.

```bash
export INSTANTML_API_KEY="instantml_..."
```

API keys can be unrestricted for an org or restricted to a project depending on
how they were created.

## Billing states

Paid signup and billing changes go through hosted checkout or portal flows.

When an org is pending payment or payment-failed, product write routes can
return a payment-required error. Reads remain separate from write gates.

Free organizations are blocked at included monthly API request and hosted
storage allowances. Paid Pro and Premium subscriptions attach Stripe-metered
overage items for hosted storage and API requests. See
[Pricing, limits, and billing](/guides/pricing-limits-billing) for the current
plan allowances and rates.

## Hosted storage

Uploaded artifact bytes are stored by the API in the org's configured artifact
backend. The public artifact row returns opaque InstantML metadata rather than a
raw storage URL.

Downloads go through:

```text
GET /api/artifacts/:artifact_id/download
```

InstantML-hosted workspace data currently uses InstantML-owned ClickHouse on
Google Cloud for User Data and tenant databases. Hosted artifact bytes use
private Cloudflare R2 buckets and stay separate from metric ingestion.

## Customer-owned storage posture

Teams that need stronger data-control boundaries can use Premium
customer-owned storage setup where product data routes to their self-hosted GCP
ClickHouse deployment. Hosted artifact bytes and customer-owned ClickHouse
bytes are accounted for differently in usage surfaces; InstantML storage
guardrails count only artifact bytes stored by InstantML.

## Secret handling

Do not commit:

- API keys.
- Session cookies.
- Auth provider secrets.
- ClickHouse credentials.
- Object-storage credentials.
