# Tables, histograms, and media

Scalar metrics explain trends. Rich objects explain evidence.

## Tables

Use tables for bounded previewable rows such as predictions, eval samples, or
per-example metrics.

```python
run.log_table_object(
    "eval/predictions",
    ["id", "target", "prediction", "score"],
    [
        {"id": "ex-1", "target": "cat", "prediction": "cat", "score": 0.98},
        {"id": "ex-2", "target": "dog", "prediction": "cat", "score": 0.61},
    ],
    step=10,
)
```

The dashboard fetches table rows through a separate bounded endpoint.

## Histograms

Use histograms for distributions such as logits, rewards, gradient norms, or
latency samples.

```python
run.log_objects(
    {"eval/confidence": ro.Histogram.from_values([0.91, 0.72, 0.88, 0.43], bins=8)},
    step=10,
)
```

Histograms appear as previews in Run Detail and artifact/object surfaces.

## Media objects

Use media objects when the dashboard should treat a stored image, audio, or
video as previewable run evidence. Media objects link to uploaded artifact bytes
from the same run.

```python
image = run.upload_file("outputs/confusion-matrix.png", artifact_type="image", step=10)
run.log_objects(
    {
        "eval/confusion_matrix": ro.Image(
            path="outputs/confusion-matrix.png",
            caption="Validation confusion matrix",
        )
    },
    step=10,
)
```

For videos and audio, upload the file bytes first, then log a rich object when
you want Run Detail and artifact surfaces to render a preview:

```python
run.upload_file("outputs/rollout.mp4", artifact_type="video", step=100)
run.log_objects(
    {"eval/rollout": ro.Video(path="outputs/rollout.mp4", caption="Evaluation rollout")},
    step=100,
)
```

External references such as object-store URIs remain metadata artifacts. They
are useful for provenance, but they are not previewable unless bytes are stored
through InstantML.

## Text

```python
run.log_text({"notes/eval": "Policy stabilized after the reward schedule change."}, step=10)
```

Text values are useful for short generated summaries, explanations, or compact
debug output.

## Mixed `log(...)` payloads

`run.log(...)` classifies values before sending requests:

```python
run.log(
    {
        "train/loss": 0.12,
        "notes/eval": "policy stabilized",
    },
    step=2,
)
```

Mixed payloads are deterministic but not atomic across routes. Metrics are sent
first, then text, objects, files, and media. If a later request fails, earlier
requests may already be stored.
