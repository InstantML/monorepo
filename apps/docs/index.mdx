# Training observability without the maze

InstantML helps small ML teams track runs, compare metrics, inspect configs,
and keep artifacts close to the training loop. Create an API key, log a run
from Python, then use the dashboard to sort, chart, and compare what happened.

## The first useful loop

```python
import instantml as ro

run = ro.init(
    project="cartpole",
    name="ppo-seed-42",
    config={"seed": 42, "algorithm": "ppo", "learning_rate": 3e-4},
    tags=["ppo", "baseline"],
    notes="First PPO baseline.",
)

for step in range(100):
    run.log(
        {
            "train/reward": step * 1.5,
            "train/loss": 1.0 / (step + 1),
            "eval/accuracy": min(1.0, 0.5 + step / 200),
        },
        step=step,
    )

run.finish()
```

In the dashboard, the project appears in the project selector, the run appears
in the run list, config values appear in Run Detail and Compare, and metric keys
become chartable series.
