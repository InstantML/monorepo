# Troubleshooting

## The SDK cannot connect

Check that the hosted API is reachable:

```bash
curl https://api.instantml.ai/healthz
```

Then confirm your SDK key is configured:

```bash
test -n "$INSTANTML_API_KEY" && echo "INSTANTML_API_KEY is set"
```

## Hosted calls are unauthorized

Check that the API key is present:

```bash
test -n "$INSTANTML_API_KEY" && echo "INSTANTML_API_KEY is set"
```

Either run `instantml login`, set `INSTANTML_API_KEY`, or pass
`api_key="instantml_..."` directly to `ro.init(...)`.

## Hosted calls are rate-limited

Short-window `429` responses include `X-InstantML-RateLimit-Scope: second` and
`Retry-After`; retry after the header delay or reduce request concurrency.

Monthly API quota `429` responses include
`X-InstantML-RateLimit-Scope: monthly` and reset at the next UTC calendar
month. Free and non-billable orgs are blocked at the monthly allowance, while
paid Pro and Premium API request overage is Stripe-metered. See
[Pricing, limits, and billing](/guides/pricing-limits-billing).

## The dashboard does not show my run

Check the project name you used in the SDK call. `project="cartpole"` appears in
the dashboard project selector as `cartpole`.

If the run was created but later logging calls failed, call `run.flush()` when
using buffering and check SDK exceptions for the failed request.

## Offline replay did not create a run

Current limitation: `init()` still needs a reachable server because run creation
is not spooled yet. `offline_dir` covers failed requests made after a run already
exists.

## Importer routes

The public API includes Import v2 job routes for local-first W&B, Neptune
Exporter, MLflow, and TensorBoard migration tooling:

- `POST /api/imports/jobs`
- `POST /api/imports/jobs/{import_id}/chunks`
- `POST /api/imports/jobs/{import_id}/commit`
- `POST /api/imports/jobs/{import_id}/cancel`

Legacy transformed JSON importer routes remain available:

- `POST /api/imports/wandb`
- `POST /api/imports/mlflow`
- `POST /api/imports/neptune`

If Neptune imports fail before parsing, confirm `pyarrow` is installed with
`pip install "instantml[imports]"` and that the path points at the exported
Parquet directory rather than a symlink. If TensorBoard sync produces no new
points, confirm the run source identity matches the original imported
TensorBoard run and that the event files contain scalar summaries.

## Generated API reference looks stale

The generated reference should match the practical API guides. If a documented
hosted route is missing, report the page URL, endpoint, and response
`x-request-id` if a request failed.
