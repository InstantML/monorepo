# Quickstart

This is the fastest hosted SaaS path. You need Python 3.11 or newer and an
InstantML account. For an interactive machine, use `instantml login` instead
of exporting an API key.

## 1. Install

Create an isolated Python environment and install the current alpha package:

```bash
python3.11 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install --pre instantml
instantml --help
```

Install optional extras only when your script needs them:

```bash
python -m pip install --pre "instantml[media]"
python -m pip install --pre "instantml[system]"
```

## 2. Log in

Authenticate once from the terminal:

```bash
instantml login
instantml whoami
```

The CLI opens a browser device-code confirmation page, then stores a scoped SDK
credential in `~/.instantml/credentials`. The Python SDK reads that credential
automatically.

The hosted SDK default is `https://api.instantml.ai`, so normal hosted users do
not need `INSTANTML_API_BASE_URL`.

## 3. Run your first script

Create `train.py`:

```python
import math
import random

import instantml as ro

run = ro.init(
    project="quickstart",
    name="baseline-seed-42",
    config={
        "seed": 42,
        "model": "tiny-mlp",
        "optimizer": "adam",
        "learning_rate": 3e-4,
    },
    tags=["quickstart", "baseline"],
    notes="First hosted InstantML run.",
)

random.seed(42)

for step in range(1, 51):
    loss = math.exp(-step / 18) + random.random() * 0.02
    accuracy = min(0.98, 0.5 + step / 120 + random.random() * 0.01)
    run.log(
        {
            "train/loss": loss,
            "eval/accuracy": accuracy,
        },
        step=step,
    )

run.finish()
print(f"InstantML run finished: {run.run_id}")
```

Run it:

```bash
python train.py
```

Open [InstantML](https://instantml.ai), choose the `quickstart` project, and
inspect the run in Runs, Metrics, Run Detail, and Compare.

## 4. CI and remote jobs

Use a secrets manager or environment variable when a job cannot use browser
login:

```bash
export INSTANTML_API_KEY="instantml_..."
python train.py
```

For the first scalar-only run, the key only needs `sdk:ingest`. Add
`artifacts:write` for file uploads, `export:read` for read/export jobs, and an
unrestricted org key with `usage:read` for usage reporting.

You can also pass the key directly:

```python
run = ro.init(project="quickstart", api_key="instantml_...")
```

## 5. Load existing runs

Use the read-only API helper to find existing runs from scripts or notebooks:

```python
import instantml as ro

api = ro.Api()
page = api.runs(
    project="quickstart",
    q="baseline",
    sort_by="metric-best",
    metric_key="eval/accuracy",
    limit=10,
)

for row in page["runs"]:
    print(row["id"], row["name"], row.get("status"))
```

`Api.runs(...)` reads the same bounded summary shape used by the dashboard. Use
`ro.attach_run("run-id")` when a resume script should continue logging into an
existing child run, such as one created by a checkpoint fork.

Download stored checkpoint or file artifacts with:

```python
path = api.download_artifact("artifact-id", "checkpoints/policy.pt")
print(path)
```

## 6. Shadow a W&B run

Use shadow logging when you want InstantML and Weights & Biases side by side
during migration. Install and authenticate W&B exactly as you normally would,
then enable `shadow_wandb`:

```bash
python -m pip install wandb
wandb login
```

```python
import instantml as ro

run = ro.init(
    project="quickstart",
    name="wandb-shadow-seed-42",
    config={"seed": 42, "optimizer": "adam"},
    tags=["shadow", "wandb"],
    shadow_wandb=True,
)

for step in range(1, 11):
    run.log({"train/loss": 1.0 / step, "eval/accuracy": step / 10}, step=step)

run.finish()
```

Artifact and checkpoint calls in a shadowed run use the InstantML artifact API.
Use a dashboard or onboarding API key with `artifacts:write` before adding
`run.log_artifact(...)` or `run.log_checkpoint_file(...)`:

```python
from pathlib import Path

import instantml as ro

run = ro.init(project="quickstart", api_key="instantml_...", shadow_wandb=True)
Path("weights.pt").write_bytes(b"replace with checkpoint bytes")
run.log_artifact(
    "weights",
    "file://weights.pt",
    artifact_type="checkpoint",
    step=10,
    metadata={"kind": "model"},
)
run.finish()
```

You can set a different W&B project or entity without changing the InstantML
project:

```python
run = ro.init(
    project="quickstart",
    shadow_wandb={"project": "wandb-comparison", "entity": "my-team"},
)
```

Or attach to an existing `wandb.Run`:

```python
import instantml as ro
import wandb

wb_run = wandb.init(project="wandb-comparison")
run = ro.init(project="quickstart", shadow_wandb=wb_run)
```

Shadow logging mirrors scalar `run.log(...)` calls, `finish()`, and local-file
metadata artifacts created with `log_artifact("name", "file://path", ...)`.
InstantML remains the source of truth for rich objects, uploaded files,
checkpoint uploads, console capture, and system metrics.

If W&B is not installed or `wandb.init(...)` fails, InstantML warns and keeps
logging to InstantML.

## 7. Keep W&B primary while mirroring to InstantML

For low-risk pilots, keep W&B as the source of truth and mirror scalar metrics
to InstantML with a one-line import swap:

```python
import instantml.wandb_mirror as wandb

run = wandb.init(project="quickstart", config={"seed": 42})
wandb.log({"train/loss": 0.25}, step=1)
run.finish()
```

The official W&B package still receives `init`, `log`, and `finish`. InstantML
mirrors scalar metrics best-effort, and InstantML-side failures warn without
interrupting W&B logging. Use `instantml_project=...`, `instantml_api_key=...`,
or `instantml_base_url=...` on `wandb.init(...)` when the mirror should use
different InstantML settings.

## 8. First failure checks

If the SDK cannot start:

```bash
instantml whoami
curl -fsS https://api.instantml.ai/health
```

If credentials are configured through CI, check presence without printing the
secret:

```bash
test -n "$INSTANTML_API_KEY" && echo "INSTANTML_API_KEY is set"
```

If the dashboard does not show the run, confirm the project name in your script
matches the project selector and call `run.finish()` or `run.flush()` before
the process exits.
