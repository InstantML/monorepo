One vocabulary. Two fonts.
Green means live.

Instrument treats the product as a flight recorder for training runs — a control room where every number is telemetry and every accent is a signal. This page is the readable specimen for the system; the shipped token source is apps/web/app/styles/tokens.css. It shows the tokens, type scale, and primitive components in both the light and dark themes.

01

Mono carries data, Archivo carries prose

If you can sort, filter, or paste it into a terminal, it's Spline Sans Mono. Titles and copy are Archivo. No third UI font.

02

Green means live

--accent is reserved for things happening now, best-yet values, and the one primary action. If everything is green, nothing is.

03

Hairlines, not shadows

Structure comes from 1px borders and one-step surface changes. The only glow is phosphor on live chart series.

04

Dense, never cramped

36px rows, a 4px spacing base, 12px gutters. Density is earned by removing chrome — data text never drops below 10px.

The proposal

Collapse two token vocabularies into one

Today the codebase has been drifting between the shipped app vocabulary (--surface, --text, --accent, --muted, --line) and reference-only names from the reimagine docs. The shipped app names are now the canonical names; the fix is to add the missing type/spacing scales, keep roles semantic, and retire feature-local aliases.

Components

Primitives

Every screen is assembled from these. When you need something new, pick the nearest primitive — panel, chip, table, or well — reuse its states, and route every value through a token.

micro-label · .mlabel
eval/return_mean — active runs

The most-used primitive: 10px mono, uppercase, 0.14em tracking, dim. Panel titles, table headers, axis furniture. Ellipsizes past ~40 chars.

buttons · .btn28px

Mono uppercase 11px. One --primary (signal-dim fill) per view — it's the verb of the page. --ghost is borderless until hover; destructive reuses the base with crit border.

inputs & query tokens
status: running × lr: > 1e-4 × + filter

Inputs are 28px inset wells; focus = signal border + dim ring. Query tokens carry a green key and remove via ×.

7px dots. .pulse adds the infinite ping ring — only for live things, a handful per screen. Color never travels alone: it always pairs with a dot, label, or glyph.

Principles

Do / Don't

When extending the system: reuse the nearest primitive, route every value through a token, and remember that if a screen seems to need a second font, the answer is no.

Do

  • Reserve --accent for live / best / the one primary action.
  • Right-align every numeric column with tabular figures.
  • Use *-dim washes for chip fills.
  • Put exactly one .mlabel in each panel head.
  • Clamp non-negative metric axes at 0.
  • Pair color with a glyph, label, or position — never color alone.

Don't

  • Use green as a general accent or success confetti.
  • Stack multiple filled buttons in a header.
  • Center or left-align numbers.
  • Put solid semantic fills behind text.
  • Let axis padding invent negative loss.
  • Add a new semantic color before a fifth meaning exists.
